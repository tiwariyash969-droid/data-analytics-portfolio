# Olist E-commerce Data Analysis | SQL & Power BI

## Project Overview
Analyzed the Olist e-commerce dataset using PostgreSQL and Power BI to understand sales performance, customer behavior, product performance, payment methods, and delivery operations.

## Tools Used
- PostgreSQL
- pgAdmin 4
- Power BI
- SQL
- DAX

## Dataset Tables
- `customers`
- `orders`
- `order_items`
- `order_payments`
- `products`

## Business Questions
1. What is the total revenue and average order value?
2. How many orders were placed?
3. Which products generate the highest revenue?
4. Which product categories perform best?
5. Which customer states generate the most revenue?
6. Which payment methods are most popular?
7. What are the monthly revenue trends?
8. How many customers are one-time versus repeat customers?
9. What percentage of orders are delivered late?

## Key Findings
- Total payment value: approximately **16.01 million**
- Total orders: **99,441**
- Repeat customers: **2,997**
- One-time customers: **93,099**
- Late delivery rate: **8.11%**

## SQL Concepts Demonstrated
- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate functions: SUM, COUNT, AVG
- GROUP BY and HAVING
- INNER JOIN
- CASE WHEN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date-based analysis using DATE_TRUNC

## Power BI Dashboard
Created an interactive Power BI dashboard using data from PostgreSQL.

Dashboard features include:
- KPI cards for key business metrics
- Monthly revenue trend analysis
- Customer and sales analysis
- Interactive slicers
- DAX measures
