# E-commerce Sales Analysis Using SQL

## Project Objective
Analyze e-commerce sales data to understand revenue,
customer behavior, and product performance.

## Tools
- PostgreSQL
- pgAdmin 4
- SQL

## Business Questions
1. What is the total revenue?
2. How many orders were placed?
3. Which products generate the highest revenue?
4. Which regions perform best?
5. What are the monthly sales trends?
6. Who are the repeat customers?
7. Which categories perform best?

## SQL Concepts
- SELECT and WHERE
- GROUP BY and ORDER BY
- Aggregate Functions
- JOINS
- CASE WHEN
- Subqueries
- CTEs
- Window Functions
