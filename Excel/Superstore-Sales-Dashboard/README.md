# Superstore Sales Performance Analysis & Dashboard

## Objective
Analyze Superstore sales and profit to identify trends across time, regions, and product categories.

## Tools
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Slicers

## Work completed
- Cleaned and transformed the dataset using Power Query.
- Analyzed monthly sales, category performance, regional results, and product profit.
- Built an interactive dashboard with KPI cards and Region and Category slicers.

## Key metrics
- Total Sales: 2.29 million
- Total Profit: 286,397
- Unique Orders: 5,009
